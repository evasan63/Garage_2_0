1st version of Garage_2_0 is based on Garage_1_0: 
Garage_1_0 is a console application representing a Garage where it is possible to park and fetch different types of vehicles. In the first version its possible to:
- Create a Garage with specified number of parking lots, how many of them has loaing possibility for ev's and a parking fee based on hourly rate,.
- Add a vehicle in to the Garage with specified Type, RegNum, Brand, FuelType, Color, NumSeats and NumWheels.
- Get a vehicle from the Garage based on RegNumber.
- List all vehicles in the Garage.
- List vehicles in the Garage of specified type (Type, Brand and Color).
- Exit the program.

New in Garage_2_0:
